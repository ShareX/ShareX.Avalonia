# Web design

Follow the target web project's existing stack, components, and visual conventions. For a new design, choose typography, spacing, color, and motion that serve the user's audience and purpose.

Implement the requested interactions, responsive layout, keyboard behavior, and loading/error states. Verify the rendered result at relevant viewport sizes. Add visual effects only when they improve the requested experience.

For Avalonia pages and dialogs, use [design-ui-window](../design-ui-window/SKILL.md).
